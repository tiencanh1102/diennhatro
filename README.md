# Nhà Cho Thuê — Phiên bản V16

## Các nâng cấp trong bản V16
1. **Thêm icon thùng rác xóa ảnh đồng hồ ở Tab Số điện:** Ngay bên phải nút *Xem ảnh cũ* và *Xem ảnh mới* có icon thùng rác đỏ giúp Quản trị viên xóa nhanh ảnh đã đính kèm và tự động đồng bộ lên máy chủ.
2. **Đồng nhất tên nút chốt số điện:** Cả 2 nút ở trên và dưới bảng ghi chỉ số điện đều đổi thành **`Lưu số điện & Kết chuyển Tiền phòng`** cho rõ ràng, đồng nhất.
3. **Tự động xóa cache web (`version.json` `16.0.0`):** Mọi thiết bị tự động cập nhật giao diện V16 mới nhất.

## Cập nhật nhanh lên V16
Giải nén `nha_cho_thue_v16.zip` và đẩy toàn bộ tệp (gồm `index.html`, `version.json`, `sw.js`, `manifest.json`, thư mục `functions`, 4 tệp icon; không cần đẩy `Code_V16_AppsScript.js`) lên GitHub / Cloudflare Pages.
