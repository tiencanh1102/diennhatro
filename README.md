# Nhà Cho Thuê — Phiên bản V17

## Các nâng cấp trong bản V17
1. **Màn hình đăng nhập Kính lỏng (Liquid Glass) đa sắc nổi bật:**
   - Thêm bảng màu nền kính lỏng tươi sáng, có lớp bóng phản quang phía trên cho từng ô **Tên phòng**, nút **Quản trị viên** và nút **Đăng nhập** (tự thích ứng đẹp cả chế độ Sáng và Tối).
2. **Khung viền hoa văn trang nghiêm cho "NỘI QUY TOÀ NHÀ":**
   - Bổ sung 4 họa tiết hoa văn góc và 4 thanh viền chuyển sắc vàng–cam–đỏ bao quanh khung nội quy, giữ nền đỏ thẫm và chữ vàng đậm nổi bật.
3. **Tự động xóa cache web (`version.json` `17.0.0`):** Mọi thiết bị tự động cập nhật giao diện V17 mới nhất.

## Cập nhật nhanh lên V17
Giải nén `nha_cho_thue_v17.zip` và đẩy toàn bộ tệp (gồm `index.html`, `version.json`, `sw.js`, `manifest.json`, thư mục `functions`, 4 tệp icon; không cần đẩy `Code_V17_AppsScript.js`) lên GitHub / Cloudflare Pages.
