Link đồng bộ Google Apps Script

Tài khoản nhận tiền (Tạo mã VietQR trên phiếu thu)

Cách gắn Google Sheets trong 2 phút:
  1. Tạo 1 file Google Sheets mới trên Google Drive của bạn.
  2. Trên thanh menu chọn Tiện ích mở rộng (Extensions) → Apps Script.
  3. Xóa code cũ, bấm Copy mã Apps Script bên dưới rồi dán vào, nhấn Lưu.
  4. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới → Ứng dụng web (Web app).
  5. Mục Thực thi với tư cách chọn Tôi (Me); mục Ai có quyền truy cập chọn Bất kỳ ai (Anyone) → Bấm Triển khai và cấp quyền.
  6. Copy URL Web App (đuôi /exec) dán sang tab Sheet & VietQR. Khi đồng bộ lần đầu, hệ thống tự tạo đủ 4 sheet trực quan: Cau_Hinh, Chi_So_Dien, Lich_Su_Hoa_Don, Bao_Cao_Thang.
